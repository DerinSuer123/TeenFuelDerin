Frequently asked questions

If you’re new to cooking, start with an “Easy” recipe and read the Teen Tips.

What tools do I need?

Most recipes use a microwave, stove, or toaster oven. Use the “Microwave” filter if that’s all you’ve got.

Are these recipes cheap?

Most are budget-friendly and use repeat ingredients (rice, eggs, yogurt, tortillas, frozen veggies).

I’m trying to eat more protein — can this help?

Yes. Use the “High protein” filter and add easy boosters like Greek yogurt, eggs, chicken, beans, or tuna.

What if I don’t like an ingredient?

Every recipe includes swaps (ex: chicken → tofu/beans, rice → pasta, spinach → any greens).
